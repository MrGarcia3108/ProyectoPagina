# Hoja de vida | Sebastian Garcia Zapata

Página web personal con mi hoja de vida: perfil profesional, formación académica, habilidades, idiomas, referencias y datos de contacto.

**Ver página:** [https://mrgarcia3108.github.io/ProyectoPagina/]

## Tecnologías

HTML5, Tailwind CSS 4 (CLI) y GitHub Pages.

## Estructura

- `index.html`: la página.
- `css/input.css`: tema y clases propias de Tailwind.
- `css/output.css`: CSS generado.
- `img/`: foto de perfil.

## Cómo ejecutarlo

Abre `index.html` en el navegador. Para editar los estilos, ejecuta `npm install` y luego `npx @tailwindcss/cli -i ./css/input.css -o ./css/output.css --watch`.
